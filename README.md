# Tank on a Field

A tiny pygame experience that lets you drive a stylised tank around a grassy field.

## Prerequisites

* Python 3.9+
* `pip` to install dependencies

## Getting started

1. Install the dependency:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the game:
   ```bash
   python tank_game.py
   ```
3. Use the arrow keys to steer the tank around the field.

## Controls

| Key | Action |
| --- | ------ |
| ⬆️  | Accelerate forward |
| ⬇️  | Reverse |
| ⬅️  | Rotate left |
| ➡️  | Rotate right |

Press the window close button to exit the app.
